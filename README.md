# ⚽ Pro Football Match Analyzer

تطبيق ويب احترافي لتحليل مباريات كرة القدم ومقارنة إحصائيات الفرق باستخدام الذكاء الاصطناعي.

## 🚀 جربه مباشرة!
يمكنك تجربة التطبيق الآن عبر الرابط التالي:
👉 [اضغط هنا لفتح التطبيق](https://footballmatchanalyzer-ilm7kd7weoxn5hnz2cnj7.streamlit.app)

## ✨ المميزات
- **واجهة تفاعلية:** إدخال إحصائيات المباراة بسهولة.
- **رسوم بيانية:** مقارنة الأداء بصرياً باستخدام `Matplotlib`.
- **تحليل ذكي:** توقع الفريق الأفضل بناءً على الأرقام (AI Prediction).
- **شعارات الفرق:** عرض تلقائي لشعارات المنتخبات.
- **تصدير النتائج:** إمكانية تحميل تقرير المباراة كملف Excel.

## 🛠️ التقنيات المستخدمة
- Python
- Streamlit
- Pandas
- Matplotlib
- NumPy

## 🏃‍♂️ كيفية التشغيل محلياً
إذا أردت تشغيل الكود على جهازك:
1. قم بتثبيت المكتبات: `pip install -r requirements.txt`
2. قم بتشغيل التطبيق: `streamlit run app.py`
